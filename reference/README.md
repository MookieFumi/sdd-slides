# Fuentes

Texto de apoyo de las dos charlas. `npm run verify:*` lo concatena (`scripts/make-source.mjs`) para comprobar,
carácter por carácter, los comandos y títulos que salen en escena.

| Archivo | Qué es |
| --- | --- |
| `guias-texto.md` | texto extraído de las dos guías de uso originales |
| `articulos.md` | extractos de los artículos de Webreactiva (OpenSpec y Spec Kit) |
| `datos-reales.md` | lo que generan y aceptan las CLI, comprobado ejecutándolas (9 oct 2026) |
| `propios.md` | textos redactados para la charla |

Las dos guías originales en HTML (`guia-uso-open-spec-es.html` y `guia-uso-github-spec-kit-es.html`) ya no están
en el repo; siguen disponibles en el historial de git (commit `e474cd9`).
